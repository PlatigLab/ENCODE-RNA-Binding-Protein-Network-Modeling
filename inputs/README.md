Folder for all the inputs that are relevant broadly to the analysis. 

📂`metadata/`: 

Metadata files from `ENCODE`. 

📂`RBP-RBP_PPI/`:

Contains `RBP-RBP PPI` info and table to map the `UniProt` IDs back to gene names. 

📂`annotations/`: 

Contains `GENCODE V24` and `GENCODE V29` annotations files used for this project.
