# ENCODE RNA Binding Protein Network Modelling

Repository for analysis of `RNA-Binding Protein (RBP)` data from the `ENCORE` project.

📂`analysis/`: 

Contains the main analyses in the sequential order done that went towards the publication. 

📂`inputs/`: 

Contains general input data that is useful across the entire repository. (e.g. `ENCORE metadata` or `RBP-RBP PPI` info). 

📂`miscellaneous_analysis/`:

Contains analyses that were not the main part of the publication but answered highly important and specific questions.
